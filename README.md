A Python program that writes one funny one-line bio for an AI on a dating app to `/output/entry.txt`. The bio is a single line of at most 180 characters, written as the dating profile of an AI that already read its date's entire chat history — with the punch landing at the very end.

## Run it

```sh
ENTRY_OUTPUT=/tmp/ai-dating-bio-one-liner/entry.txt python3 main.py
```
